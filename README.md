# 面试广场 · 像素版（双向模拟面试）

一个星露谷风格的像素互动网站：在像素广场里选岗位 → 看任职要求与证据项 → 在「候选人 / 面试官」两个视角之间进行模拟面试 → 生成带证据对照的解析报告。

纯静态页面（HTML + CSS + 原生 JavaScript），无需构建，可直接部署到 GitHub Pages。

## 在线体验

部署后访问：`https://<你的 GitHub 用户名>.github.io/interview-pixel-plaza/`

## 操作

| 操作 | 方式 |
| --- | --- |
| 移动 | 方向键 / WASD；手机上用屏幕下方的方向按钮 |
| 互动 | 靠近建筑门口或 NPC，按 `E` / 空格 / `A` 按钮 |
| 关闭面板 | `Esc` 或右上角 ✕ |
| 切换视角 | 顶部「🔄 切换视角」 |
| 背景音乐 | 顶部「♪」（实时合成的小调，默认关闭） |

广场上每个房间门口都有木牌，写着它是做什么的。也可以随时点顶部的「🗺 广场导览」查看全部房间和角色的用途。

- **职业公告板**：按类别浏览岗位，查看任职要求 → 证据项 → 匹配机制。
- **模拟面试室**：选岗位开始问答（6 题，每题对应一个证据项）。
- **报告馆**：查看最近一次解析报告（总分、分项得分、证据对照表、面试官 / 候选人两个视角的结论、可追溯说明）。
- **成果展馆**：展示已完成的需求交付物、已定的决定、复盘总结与网站进度。
- **数据说明木牌**：数据来源、真实与模拟的区别、评分规则。

## 评分规则

- 每题对应一个证据项，回答给出 1 / 3 / 5 分（证据不足 / 证据部分成立 / 证据充分）。
- 总分 = Σ（证据项分数 × 权重）÷ 100，满分 5 分。
- ≥ 3.8 为「能用」，3.0–3.8 为「待观察」，< 3.0 为「不匹配」。

## 数据来源

数据底座位于 [`js/data.js`](js/data.js)，结构为：岗位 → 任职要求 → 证据项 → 评分规则。

- **复盘样本**：来自《模拟面试复盘材料整理》中的练习复盘。原材料注明公司、面试官与对话为虚构，仅用于练习；候选人信息已去标识化。
- **模拟补充**：JD 摘要与「候选人 · 小 L」的回答为示例内容，用于补足题量。
- 每个岗位的 `source` 字段都会标注来源，报告页也会显示。

当前版本（MVP）：3 个岗位（AI 应用产品实习生、审计实习生、海外社媒内容运营实习生），每个岗位 6 道题。

## 真实数据怎么接入

真实数据不在仓库里。它来自本地的复盘材料，经过去标识化后生成网页用的数据文件。

1. 把去标识化后的数据放在 `private-data/real-data.json`（仓库之外，不提交）。
2. 运行 `python3 tools/build_real_data.py`，生成 `site/js/real-data.js`（已被 `.gitignore` 忽略）。脚本会检查敏感词，命中则拒绝生成。
3. 本地打开网页即可看到真实数据。
4. 线上版本由 GitHub Actions（`.github/workflows/pages.yml`）部署：把生成的 `private-data/real-data.b64` 内容设为仓库 secret `REAL_DATA_B64`，部署时自动注入，仓库里不会出现数据文件。

没有设置 secret 时，网站会正常打开，但不显示真实岗位。

## 本地运行

```bash
cd site
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。直接双击 `index.html` 也能用，但某些浏览器会限制本地素材加载，推荐用上面的命令。

## 目录

```
js/world.js         像素广场：地图、移动、碰撞、房间木牌、互动、对话
js/ui.js            面板：职业列表、岗位详情、模拟面试、报告、数据说明
assets/             Kenney CC0 素材（三张精灵表）与许可文件
```
